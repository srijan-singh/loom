# loom

> [!NOTE]
> **Exploring the architecture?** Browse the complete codebase index and query docs on [DeepWiki](https://deepwiki.com/srijan-singh/loom).

A local-first desktop application for building and running your own AI agent workforce. Define skills, connect your tools via MCP (GitHub, Figma, filesystem, etc.), assemble agents into supervisor/worker workflows on a visual canvas, and watch them execute in real time - all while your data and API keys stay on your machine.
